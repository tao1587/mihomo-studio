# Proposal: 简化为单列生成流程

状态：`archived`

## 问题

桌面三栏布局长期占用左右两侧空间：左栏只是重复页面已有的步骤标题；右栏大部分内容是草案说明，真正高频的操作只有“生成严格隐私 YAML”。常驻两栏压缩节点和规则编辑区域，也让生成入口与最终结果割裂。

## 目标

- 删除左侧步骤导航，释放编辑空间；
- 删除常驻右侧栏，把“生成与结果”放到主流程底部；
- 默认直接显示生成状态与主按钮；
- 策略组、规则顺序和隐私约束收进默认折叠的“编译计划”；
- 生成后在同一区域显示报告、敏感 YAML 展开与复制操作；
- 保留来源、模式、规则、镜像、编译和错误语义。

## 非目标

- 不改变 Rust、IPC、草案或 YAML 输出；
- 不增加文件导出或 Clash Verge 自动同步；
- 不把静态生成描述为 Mihomo、DNS 路径或出口已验证。

## 验收场景

### 场景：桌面主流程

- **WHEN** 用户打开桌面工作区
- **THEN** 页面没有左侧步骤栏和常驻右侧说明栏
- **AND** 来源、规则等编辑区域使用居中的单列可用宽度
- **AND** “生成严格隐私 YAML”位于主流程底部的“生成与结果”区。

### 场景：查看说明

- **WHEN** 用户需要检查策略组、规则顺序或隐私硬约束
- **THEN** 用户主动展开“编译计划”
- **AND** 默认页面不被这些说明占据。

### 场景：生成完成

- **WHEN** 严格编译成功
- **THEN** 同一区域展示无秘密报告
- **AND** 敏感 YAML 仍需主动展开后查看或复制。

## 影响范围

- 删除：`src/app/useWorkspaceNavigation.ts` 及其测试；
- 当前目录没有 Git 元数据，不初始化仓库。
