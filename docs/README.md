# 文档地图

当前实现与行为契约统一从 [`../openspec/project.md`](../openspec/project.md) 进入。

## 当前真相

- `openspec/project.md`：AI 与开发者入口；
- `openspec/specs/*/spec.md`：按能力拆分的当前契约；
- `openspec/spec-index.json`：机器可读的实现与验证映射；
- `openspec/roadmap.md`：尚未实现的跨能力工作；
- `openspec/changes/`：待确认或实施中的行为变化。

## 背景与证据

以下文档保留为产品形成过程、研究证据或阶段背景。与当前能力 Spec 冲突时，以 drift 处理，不把它们作为并行真相：

- `PRODUCT_PLAN.md`、`UX_FLOW.md`：产品愿景与交互背景；
- `ARCHITECTURE.md`：早期目标架构；
- `DECISIONS.md`：已记录的产品和架构决策；
- `IMPLEMENTATION_PLAN.md`、`IMPLEMENTATION_STATUS.md`：阶段计划和 2026-08-14 状态快照；
- `SOURCE_INGESTION.md`、`RULE_SOURCES_AND_DEDUP.md`：专题设计背景；
- `RULE_ECOSYSTEM_RESEARCH.md`、`NAS_REFERENCE_AUDIT.md`：时间绑定的外部研究与参考实现审计。

研究快照中的热度、许可证、上游维护状态和远程地址都需要在使用前重新核对。
